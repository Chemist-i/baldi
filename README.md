# Карткова гра — мережева версія

Сервер (Node.js + WebSocket) тримає стан гри, кожен гравець бачить лише свою руку
та кількість карт інших. Правила, підсвітка дозволених карт і стіл — ті самі, що
й у перевіреному однопристрійному прототипі.

## 1. Встановлення

Потрібен [Node.js](https://nodejs.org) (версія 18+).

```bash
cd card-game-multiplayer
npm install
```

## 2. Запуск сервера

```bash
npm start
```

У консолі з'явиться:
```
Сервер карткової гри запущено: http://localhost:3000
```

## 3. Гра по локальній мережі (Wi-Fi/LAN)

Всі гравці мають бути в **одній мережі** (наприклад, один Wi-Fi роутер).

1. На комп'ютері, де запущено сервер, дізнайтесь локальну IP-адресу:
   - Windows: `ipconfig` → шукайте "IPv4 Address" (напр. `192.168.1.25`)
   - Mac/Linux: `ifconfig` або `ip addr`
2. Інші гравці відкривають у браузері: `http://192.168.1.25:3000` (свою IP підставте)
3. Один гравець натискає "Створити кімнату", отримує код (4 літери) і повідомляє його іншим.
4. Інші вводять цей код і тиснуть "Приєднатись".
5. Хост (перший гравець) тисне "Почати гру", коли всі зайшли.

## 4. Гра через інтернет (гравці в різних мережах)

Найпростіший спосіб без купівлі хостингу — тимчасовий тунель:

### Варіант А: ngrok
```bash
npm start
# в іншому терміналі:
npx ngrok http 3000
```
ngrok видасть публічне посилання (напр. `https://abcd1234.ngrok-free.app`) —
дайте його іншим гравцям замість локальної IP.

### Варіант Б: постійний хостинг
Для гри без тунелю можна задеплоїти цей проєкт на безкоштовний план
Render.com, Railway.app або Fly.io — усі підтримують Node.js + WebSocket
"із коробки". Достатньо завантажити цю папку як Git-репозиторій і вказати
команду запуску `npm start`.

## Правила гри

### Терміни

| Термін | Значення |
|---|---|
| **Стіл (черга)** | Карти, покладені у поточному раунді. Кожна наступна карта кладеться поверх — має накрити попередню. |
| **Верхня карта** | Остання карта в черзі столу — саме її зараз потрібно накрити. |
| **Найстаріша карта** | Перша карта, покладена в поточному раунді — саме її забирають при невдалому накритті. |
| **Козир** | Чирва (♥) — б'є будь-яку іншу масть, крім піки (див. виняток). |
| **Виняток піки** | Піку (♠) можна накрити лише пікою більшого номіналу — козир на піку не діє. |
| **Активний гравець** | Гравець, який ще не спорожнив руку (не вибув). |
| **Відбій** | Успішне завершення раунду: стіл очищується без штрафу нікому. |
| **Атакуючий** | Гравець, який починає раунд, кладучи першу (будь-яку) карту на порожній стіл. |

### Правила

1. Колода — 36 або 52 карти.
2. Карти роздаються всім гравцям порівну; залишок (якщо не ділиться націло) у грі не використовується.
3. Перший раунд починає гравець, визначений жеребкуванням.
4. Атакуючий кладе на порожній стіл будь-яку карту.
5. Кожен наступний гравець по черзі має накрити верхню карту столу карткою більшого номіналу тієї самої масті, або козирем (чирвою) — з винятком для піки (п. 6).
6. Піку можна накрити тільки пікою більшого номіналу.
7. Якщо гравець не може або не хоче накривати — він забирає собі найстарішу карту зі столу (першу, покладену в цьому раунді).
8. Після взяття карти хід переходить до наступного гравця по колу; стіл при цьому не очищується.
9. Раунд завершується відбоєм, коли кількість карт на столі досягає кількості активних гравців — стіл очищується, і новий раунд починає той, хто поклав останню (верхню) карту.
10. Гравець, що спорожнив руку, вибуває з активної гри (безпечний).
11. Гра завершується, коли активним лишається один гравець — він програє.
12. Якщо всі гравці спорожнюють руки одночасно — нічия.

## Обмеження цього прототипу

- Немає збереження стану при перезапуску сервера (гра в пам'яті процесу).
- Якщо гравець розриває з'єднання посеред гри, його місце не звільняється
  і не передається іншому — потрібно перезапускати кімнату.
- Максимум 6 гравців на кімнату (як і в оригінальних правилах).
